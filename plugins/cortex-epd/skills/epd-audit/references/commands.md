# CLI command reference

Generated from cortex-epd schema (CLI 0.1.0-dev.22.candidate.41820743400.1.2). Do not edit by hand.

## Contents

Global options and exit codes follow, then one input/output contract per public command.

## Envelope

stdout: {ok:true,data,meta:{version,command}} or {ok:false,error:{code,message,hint?,retryable,details?},meta}.
stderr: authorization/progress events. A success envelope may still exit 10 or 20; inspect the outcome.

## Global options

- --format (-f): Output format; json when stdout is not a terminal
- --fields: Only these top-level fields of data
- --progress: Progress events as NDJSON on stderr
- --yes (-y): Skip confirmation (confirmation=user_required commands only)
- --profile: Signed-in account to use for this call
- --data-dir: Override the data directory
- --verbose (-v): More detail on stderr
- --debug: Debug log (never credentials or material text)
- --no-color: Disable color
- --timeout: Authorization and network timeout in seconds; model requests use the review policy instead
- --help (-h): Show help
