Use documented read-only schema, profile and status commands if needed. Explain coverage and readiness gaps; an EPD-only public-review request is not automatically an incomplete verifier engagement. Return the proposed engagement, confirmed versus unresolved facts and the material list. Do not register or copy materials, answer intake questions, install runtimes, log in, run a review or incur model costs merely to prepare this handoff.
